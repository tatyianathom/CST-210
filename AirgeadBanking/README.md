I developed a C++ application for Airgead Banking that helps users understand compound interest by comparing investment growth with and without monthly deposits. I did particularly well at separating the interface from the calculations and validating user input. I could improve the code by making constructor declarations consistent, adding practical input limits, and creating automated tests to improve reliability and efficiency. The most challenging parts were calculating monthly interest and rejecting invalid input, which I addressed by breaking the logic into smaller steps and checking the requirements. C++ documentation, compiler warnings, and AI-assisted explanations are useful additions to my support network. This project strengthened transferable skills in object-oriented programming, input validation, exception handling, and problem-solving. Descriptive names, focused functions, and separate header and implementation files made the program readable, maintainable, and adaptable.
